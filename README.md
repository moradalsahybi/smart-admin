# Smart Admin UI

A clean and responsive admin dashboard UI designed for managing user data and analytics.  
Focuses on simplicity, clarity, and an excellent user experience.

## Features
- Dashboard with user statistics
- Cards, tables, and icons for better data visualization
- Responsive layout across all screen sizes
- Minimalist and modern design
